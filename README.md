# Determinants of Translation Readthrough in Eukaryotes

This repository contains the code used for feature generation, machine learning model training and evaluation, and randomized genome validation in the accompanying study.

## Repository Structure

```
.
├── feature_extraction/
│   ├── orig_genome/
│   └── rand_genomes/
└── notebooks/

```

### `feature_extraction/`

Contains MATLAB and Python scripts used to generate the feature tables used for machine learning analyses.

- `orig_genome/` – feature generation pipeline for the original *S. cerevisiae* genome.
- `rand_genomes/` – feature generation pipeline for the randomized genomes used in the validation experiments.

### `notebooks/`

Contains the Jupyter notebooks used for the machine learning analyses.

- `compare-models.ipynb` – model training, hyperparameter optimization, performance evaluation, feature importance analysis, and SHAP analysis.
- `randomized-genome.ipynb` – validation of the trained XGBoost model using randomized genomes.

## Data availability

Large input datasets are not included in this repository. The analyses use publicly available yeast genome, UTR annotation, tRNA, and Ribo-Seq readthrough datasets described in the study.

The feature tables used for the machine learning analyses are generated by the scripts in `feature_extraction/`.
